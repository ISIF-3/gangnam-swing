# 강남 스윙 (Gangnam Swing)

강남역 주변 실제 지도 데이터 위에서 양손 줄을 쏘아 빌딩 사이를 날아다니는 브라우저 3D 게임입니다.

**▶ 플레이: https://isif-3.github.io/gangnam-swing/**

설치 없이 브라우저(Chrome 권장)에서 바로 실행됩니다.

## 조작법

| 입력 | 동작 |
|---|---|
| `W` `A` `S` `D` | 이동 / 공중에서 방향·균형 |
| `Space` | 점프 / 매달린 상태에서는 **잡아채기** (줄을 확 당기고 놓아 새총처럼 튕겨 나감) |
| `Shift` | 달리기 / 매달린 상태에서는 **줄 감기** (연결 지점 쪽으로 끌려감) |
| 좌클릭 | 왼손 줄 발사 (누르고 있으면 매달림, 떼면 놓음) |
| 우클릭 | 오른손 줄 발사 |
| 공중에서 벽에 닿은 채 이동 키 | 벽 달리기 (빠를 때) / 벽 붙기 (느릴 때) |
| 벽에서 `Space` | 벽 점프 |
| `V` | 3인칭 / 1인칭 시점 전환 |
| 방향키 | 시야 회전 (보조) |
| `R` | 시작 위치로 |
| `Esc` | 일시정지 · 설정 |

설정 메뉴에서 줄 발사 속도, 최대 사거리, 연결 시 당김, 줄 감기 속도, 잡아채기 힘, 놓을 때 가속, 탄성, 중력, 공중 제어력, 마우스 감도, 시야각을 조절할 수 있습니다.

## 점수와 코인

- **코인·보석**: 옥상, 빌딩 사이 공중(스윙해야 닿는 곳)에 코인(100점)이 있고, 가장 높은 옥상과 좁은 골목에 보석(500점)이 숨어 있습니다. 위치는 지도에서 고정 시드로 정해져 누구에게나 같고, 모은 코인은 브라우저에 저장됩니다. 미니맵에는 코인만 표시됩니다.
- **콤보**: 공중에 있는 동안 빠른 비행, 스윙, 벽 달리기, 벽 스치기(아슬아슬), 놓는 타이밍 가속, 벽 점프, 잡아채기, 구르기 착지로 점수가 쌓입니다. 스윙과 기술마다 배율이 올라가고(최대 ×5), 땅에 잠시 서 있으면 점수로 확정됩니다. 벽에 아주 세게 부딪히면 콤보가 날아갑니다.

## 물리

- **줄 장력**: 팽팽한 줄은 매 순간 장력을 계산합니다 (`T = v_t² / r + 중력의 줄 방향 성분`). 화면 왼쪽 위에 G 단위로 표시되고, 장력이 클수록 줄이 굵어 보입니다.
- **몸 기울기**: 몸통 축이 줄 장력 벡터(양손이면 합력) 방향으로 관성 있게 기울고, 줄 잡은 팔은 줄과 일직선, 다리는 속도 반대 방향으로 끌립니다. 3인칭 카메라도 몸의 옆 기울기를 살짝 따라갑니다.
- **줄 감기**: 감는 동안 연결 지점에 대한 각운동량이 보존되어 줄이 짧아질수록 스윙이 빨라집니다.
- **놓는 타이밍**: 스윙 최저점을 지나 올라가는 중에 줄을 놓으면 진행 방향으로 추가 가속을 받습니다.
- **줄 처짐**: 느슨한 줄은 같은 길이의 포물선으로 아래로 처져 보입니다.
- **모서리 감기**: 몸과 회전 중심 사이를 건물이 가로막으면 줄이 그 건물 모서리(또는 옥상 끝)에 걸리고, 그 점을 중심으로 남은 길이만큼 돕니다. 반대로 돌아 나오면 다시 풀립니다.
- **충돌**: 빠른 속도에서도 벽을 뚫지 않도록 이동 경로를 먼저 검사합니다. 세게 부딪히면 살짝 튕기며 화면이 흔들립니다.
- **착지**: 높은 곳에서 떨어질 때 움직이고 있으면 앞구르기로 속도를 살리고, 제자리면 무릎을 굽혀 충격을 받습니다.
- **고정 타임스텝**: 물리는 화면 프레임과 상관없이 1/240초 간격으로 계산되어, 모니터 주사율이 달라도 같은 조작이면 같은 결과가 나옵니다.

## 캐릭터

골반·척추·가슴·목·머리와 팔꿈치·무릎 관절이 있는 몸입니다. 손과 발목의 목표 위치를 정하면 2관절 IK(역기구학)로 팔다리 각도를 계산합니다. 걷기·달리기 보폭, 공중에서 끌리는 다리, 줄을 향해 뻗는 팔, 시선 방향으로 돌아가는 머리, 구르기가 모두 이 방식으로 움직입니다.

마우스 고정(pointer lock)을 지원하지 않는 환경에서는 자동으로 "마우스 고정 없음 모드"로 실행됩니다. 이 모드에서는 마우스를 화면 가장자리로 밀거나 방향키로 시야를 돌립니다.

## 지도 데이터

- 강남역 주변 약 1.5km × 1.5km 영역의 건물 외곽선과 도로를 [OpenStreetMap](https://www.openstreetmap.org/)에서 가져왔습니다 (스냅샷: 2026-11-23).
- 높이(`height`)나 층수(`building:levels`) 정보가 있는 건물은 그 값을 쓰고, 없는 건물은 바닥 면적에 따라 랜덤 높이(시드 고정)로 채웁니다.
- 좌표는 강남역을 원점으로 한 미터 단위입니다 (`+x` 동쪽, `+z` 남쪽).

## 로컬에서 실행

```powershell
powershell -ExecutionPolicy Bypass -File serve.ps1
```

실행 후 브라우저에서 http://localhost:8765 를 엽니다. three.js를 CDN에서 불러오므로 인터넷 연결이 필요합니다.

## 파일 구성

- `index.html` — 게임 본체 (three.js 0.160)
- `city_data.js` — OpenStreetMap에서 변환한 건물·도로 데이터
- `serve.ps1` — 로컬 테스트용 간단한 정적 파일 서버
